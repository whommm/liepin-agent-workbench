# 猎聘寻访 Agent 工作台

这是一个全新的桌面端寻访 Agent 项目，和旧项目 `E:\Myproject\lietou` 完全隔离。

当前版本已包含：

1. Agent Session / Round / Candidate / MatchResult 数据模型。
2. SQLite 主存储。
3. Agent 搜索、观察、抽样、详情抓取、异步匹配、复盘闭环。
4. BrowserQueue 串行浏览器动作抽象。
5. MatchQueue 并发匹配抽象。
6. PySide6 作战室 UI。
7. 真实猎聘 Playwright 浏览器、搜索结果卡片解析、候选人详情抓取。
8. 真实 OpenAI 兼容 LLM Agent 决策和候选人匹配。
9. 任务级继续、终止、删除、导出按钮。
10. 重启后自动识别上次中断的运行中任务，并转为可继续状态。
11. Agent 时间线和详细日志面板。
12. 新建任务后的“匹配词与岗位要求”人工确认流程。
13. 候选人卡片判断、匹配证据包、多来源记录和效率总结导出。

## 启动

### 开发环境

安装依赖：

```powershell
python -m pip install -e .[dev]
```

启动桌面程序：

```powershell
python -m liepin_agent.main
```

### 虚拟环境（推荐）

项目提供了虚拟环境管理脚本：

1. **创建虚拟环境**：双击运行 `创建虚拟环境.bat`
   - 自动创建 `.venv` 虚拟环境
   - 安装项目依赖 + PyInstaller 打包工具
   - 自动安装 Playwright Chromium 浏览器

2. **启动程序**：`.venv\Scripts\python -m liepin_agent.main`

### 打包为 EXE

使用 PyInstaller 打包成独立可执行文件：

1. 确保已创建虚拟环境（见上一步）
2. 双击运行 `打包为exe.bat`
3. 打包完成后，输出在 `dist\猎聘寻访Agent工作台\` 目录

打包后输出单个可执行文件：
- `猎聘寻访Agent工作台.exe`（约 110MB）— 双击即可运行

首次运行后，exe 同级目录会自动生成：
- `config.json` + `.env` — 配置文件
- `liepin_agent_workbench.db` — SQLite 数据库
- `browser_profile/` — 浏览器 Profile 目录
- `exports/` — 导出文件目录
- `logs/` — 运行日志

> **注意**：
> - 首次启动会稍慢（需要把依赖解压到临时目录）
> - 目标机器若已安装 **Edge** 或 **Chrome**，程序会自动调用系统浏览器，无需额外操作
> - 仅在目标机器没有 Edge/Chrome 时，才需要运行 `playwright install chromium`

运行测试：

```powershell
python -m pytest
```

真实运行预检：

```powershell
python -m liepin_agent.check_real_runtime
```

## 使用前配置

首次使用请在界面右上角打开“设置”，填入：

1. API Base URL
2. API Key
3. 模型名称
4. 浏览器通道与 profile 目录

可以先点击“打开猎聘”，系统会打开猎聘搜索页；如果尚未登录，会自动转到猎聘首页/登录入口。你也可以直接开始任务，系统发现未登录时会自动打开猎聘页面并提示登录。

顶部的“关闭浏览器”按钮会安全关闭 Playwright 浏览器上下文；如果有任务仍在运行，系统会先询问是否停止任务再关闭，避免后台线程继续操作已关闭的浏览器。

新建寻访任务后，系统会先生成“匹配词与岗位要求”草案。请人工检查并修改：

1. 岗位关键技能 / 背景词：每行一个关键词。
2. 岗位要求描述：一段简洁、可人工理解的判断标准。

点击“确认寻访基准”或“确认并开始”后，Agent 才会开始搜索。后续搜索、详情抓取、匹配解释和复盘都会基于这个已确认版本。

## 任务状态说明

任务列表中的每个任务都有独立按钮：

1. 继续：启动或恢复该任务。
2. 终止：请求停止该任务。
3. 导出：导出该任务候选人。Excel 会包含推荐总览、合格/待复核/不合格分组和全字段明细，同时生成每位候选人的 Word 档案。
4. 删除：删除该任务及全部候选人、日志和匹配结果。

任务状态中：

1. 待确认基准：AI 已生成草案，等待人工确认。
2. 已确认，待开始：可以点击开始/继续。
3. 运行中：Agent 正在执行搜索、抓详情或匹配。
4. 等待人工确认：单步/监督模式下等待继续。

如果程序关闭时任务仍在运行，下次启动会自动把它转为暂停状态，并写入“运行中断已恢复”日志，不会继续假装运行中。

## 设计边界

本项目定位为寻访辅助和证据整理工具，不做自动雇佣决策：

1. 不自动淘汰候选人。
2. 不自动联系候选人；打招呼只能由人工在任务结束或暂停后选中候选人手动触发。
3. 不把分数作为最终判断。
4. 匹配结果应以证据、缺口、风险和待确认问题为核心，A/B/C/D 只是标签。
